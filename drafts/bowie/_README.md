## Cross-cutting fixes before ANY of these publish

1. **Reconcile the home count.** Pages variously say "7,000" and "7,500" Levitt homes. Pick one.
2. **Normalize the H1 format.** Set is inconsistent ("20-Yard" vs "20 Yard" vs "20-yard", stray periods).
   Standardize to: `20-Yard Dumpster Rental in [Place], MD`.
3. **URL / canonical plan needed.** Neighborhood pages would sit *under* a city that already has an
   auto-generated `/locations/bowie/20-yard` page. We need a URL scheme (e.g.
   `/locations/bowie/belair/20-yard`) and canonicals so they don't compete with the city page.
4. **"Belair" disambiguation.** Must anchor to Bowie/PG County — there's a separate Bel Air, MD
   (Harford County) ~70 miles away that Google could confuse it with.
5. **The asbestos claim is liability-sensitive.** Verify the source and have the wording reviewed
   before it goes live — it's a strong, useful differentiator but it's a claim with legal weight.
